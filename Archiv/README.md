# Archiv

Abgelöste Stände. Sie werden nicht gelöscht, sondern hierher verschoben. Die Werkzeuge durchsuchen diesen Ordner nie, Obsidian blendet ihn in Suche und Graph aus: Dateien hier haben oft dieselben Namen wie die gültigen. Ein Assistent verwendet nichts aus diesem Ordner als Quelle.

Je abgelegtem Stand ein Abschnitt mit Datum, Grund und dem Verweis auf die gültige Fassung.
