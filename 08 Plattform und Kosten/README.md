# Modul 08 Plattform und Kosten

**Welcher Weg, zu welchen Kosten, mit welchem Nutzen, und was kommt zuerst?**

Dieser Ordner ist leer, bis eine Methode aus dem Methoden-Repo ihn füllt. Ob der Fall das Modul braucht, steht in [fall.md](../00%20Steuerung/fall.md).

## Fragen, die hier beantwortet werden

- Was leistet Nichtstun, Prozessverbesserung ohne KI, Kaufen, Bauen, Partnerschaft?
- Welche Anforderungen schließen eine Alternative aus, bevor gewichtet wird?
- Welcher eigene Test kann eine Anbieterbehauptung widerlegen?
- Welche Kosten entstehen intern und extern über denselben Zeitraum?
- Wird frei werdende Zeit tatsächlich zahlungswirksam?
- An welcher Annahme kippt die Rechnung?
- Welches Vorhaben kommt bei begrenztem Budget zuerst, und warum?

## Woraus gelesen wird

Steckbriefe (Ablauf heute), zahlen, annahmen (Bandbreiten), systeme-daten. Was dort fehlt, wird eine Zeile im [Erhebungsplan](../01%20Erhebung/erhebungsplan.md).

## Ebene

Rechnung und Auswahl je Vorhaben, Priorisierung über das Portfolio.
