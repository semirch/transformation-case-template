# Auszüge

Was aus einer Quelle für den Fall gebraucht wird, in eigenen Worten oder als kurzes Zitat, je Quelle eine Datei: `Q-007.md`. Auszüge gehen ins Repo, das Original bleibt im [Rohmaterial](../Rohmaterial/README.md).

Ein Auszug ist noch kein Befund. Er hält fest, was die Quelle sagt. Die Einordnung geschieht in der führenden Notiz, die auf den Auszug verweist.

Je Aussage eine Zeile:

| Aussage | Fundstelle (Seite, Abschnitt, Zeitmarke) | Aussageart | Übernommen in |
|---|---|---|---|
