# Rohmaterial

Originaldokumente, Exporte, Aufzeichnungen und Transkripte. **Alles in diesem Ordner außer dieser Datei bleibt lokal:** Die `.gitignore` schließt es vom Repo aus. Wer das für einen Fall ändern will, hält die Erlaubnis zuerst in [datenverarbeitung.md](../../00%20Steuerung/datenverarbeitung.md) fest.

Dateien nach ihrer Quellenkennung benennen, etwa `Q-007-organigramm.pdf`. Welches Werkzeug Rohmaterial lesen darf, steht ebenfalls in der Datenverarbeitung. Ins Repo gehen die [Auszüge](../Ausz%C3%BCge/README.md).
