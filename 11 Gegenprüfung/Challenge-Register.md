# Challenge-Register: Zusammenhänge gegenprüfen

**Stand:** TT.MM.JJJJ

Jede Analyse stützt sich auf Zusammenhänge, die selten jemand prüft: dass die Daten für die gewünschte Qualität reichen, dass Nutzung zu Nutzen wird, dass gesparte Zeit Geld spart. Dieses Register macht daraus Hypothesen, die scheitern können. Jede hat eine eigene Notiz mit der Frage, was sie widerlegen würde.

Zuerst den Fall unabhängig erheben, dann gegenprüfen. Wer mit den Hypothesen beginnt, findet sie bestätigt.
